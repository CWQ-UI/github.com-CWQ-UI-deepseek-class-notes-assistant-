### 核心内容

- **一、线性回归的基本思路**
  - 用一个线性函数去拟合数据。
  - 假设函数为 h(x) = θ0 + θ1x。

- **二、损失函数（均方误差）**
  - 损失函数采用均方误差。
  - 公式：J(θ) = 1/(2m) × Σ（i 从 1 到 m）[h(xi) − yi]²。

- **三、用梯度下降求最优参数**
  - 求最优参数的方法是梯度下降。
  - 参数更新式：θj = θj − α ×（偏导数）。
  - 其中 α 是学习率。

- **四、学习率的影响**
  - 学习率太大：会震荡、不收敛。
  - 学习率太小：收敛太慢。

- **五、特征缩放**
  - 特征缩放很重要。
  - 忘了归一化的话，梯度下降会很慢。

- **六、举例**
  - 房价预测：以面积作为特征。
